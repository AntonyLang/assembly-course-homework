观察：
1. 两个 for 循环被翻译为初始化、CMP、条件跳转和自增指令。
2. 这里没有生成 LOOP 指令；编译器使用 JLE/JG 等条件跳转。
3. ECX 在这里用于传递函数参数，不能当成课程程序中的 CX 循环计数器。
4. 当前地址对应上述编译器、编译选项与源码；修改源码或工具版本后应重新查看反汇编。
5. 前两题是 16 位 DOS 程序，采用 INT 21h；本题是 64 位 Windows C 程序，采用 C 运行库的 putchar。
