# 作业五：递归 Fibonacci

`fib.asm`、`fib.exe` 为 8086 DOS 程序；`fib_c.c`、`fib_c.exe` 为 C 版本，运行于 Windows x64。输入范围为 1..100，取 F(0)=0、F(1)=1。C 的实际反汇编及注释见 `fib_c_annotated.txt`。

```text
Input n (1..100): 100
F(n): 354224848179261915075
```

F(100) 超过 64 位整数范围。汇编使用五个 16 位字，低位到高位依次放在 AX、BX、CX、DX、SI 中，共 80 位。C 使用五个 uint16_t，并以 uint32_t 计算每个字的和与进位。两种实现均检查了 n=1..100 的结果。

## 递归与寄存器

DI 传入 n，`fib` 递归调用自身求 F(n-1) 和 F(n-2)。前一个结果的五个字先压栈保存，第二次调用返回后依次弹出，以 ADD、ADC 完成带进位相加。POP 不改变进位标志，所以可放在相邻两次 ADC 之间。

ready 和 cache 保存已求得的项。首次求值仍沿递归调用完成，重复遇到同一个 n 时直接取缓存，避免两路递归造成指数级重复计算。输入 100 时递归深度仍可达到 100，缓存不能代替栈空间的分配。

cache 每项占 10 字节，用 BP 计算 `n*10`。BP 寻址默认使用 SS，因此访问数据段缓存时写明 `ds:cache[bp]`。fib 保留调用者的 DI、BP；其他五个寄存器作为结果返回。

## 栈空间

`.stack 1000h` 分配 4096 字节，DOS EXE 头初始化 SS、SP，程序入口的 SP=1000h。

每层近 CALL 的返回地址占 2 字节，保存 BP、DI 占 4 字节，暂存前一个结果最多占 10 字节。按最多 100 层、每层最多 16 字节估算，递归部分不超过 1600 字节。输出最多 21 位十进制数，数字逆序压栈另占 42 字节；输出在递归返回后进行，不与全部递归帧同时占用。4096 字节可容纳本程序这些开销，并保留中断调用余量。

打印时把五个寄存器复制到 number，从最高字到最低字连续除以 10，DX 保留上一字的余数。最终余数是一个十进制位，压栈后逆序输出。数值 0 也执行一次转换。

## 单步观察

在 `debug fib.exe` 中执行：

```text
t
t
r di
3
g=001e 002c
r
```

前两步初始化 DS，设置 DI=3 后从主过程的 CALL 指令（001E）开始，跳过键盘输入，停在 fib 入口（002C）。之后用 `t` 进入递归，不用跳过 CALL 的方式跟踪。

| 动作 | SP |
| --- | --- |
| 主过程调用 fib(3) 后 | 0FFE |
| push bp | 0FFC |
| push di | 0FFA |
| 递归 CALL fib(2) 后 | 0FF8 |
| fib(2) 保存 BP、DI 后 | 0FF4 |
| fib(1) 返回段、尚未恢复 DI/BP | 0FEE |
| pop di | 0FF0 |
| pop bp | 0FF2 |
| ret 回到 fib(2) 的 0039 | 0FF4 |

前八次 `t` 后，可执行 `g 00a4` 停在第一层基例的返回段，再执行三次 `t`，观察 POP、POP、RET。返回时 AX=1，其余四个结果寄存器为 0。偏移对应当前提交的 EXE，重新修改程序后应先用 `u` 核对。

递归的局部状态必须留给本层调用。这里不仅要保存 n，还要在第二次递归前保存第一次的结果；只保留返回地址并不能保证计算正确。进位也是状态的一部分，不能在 ADD/ADC 链中插入会破坏 CF 的算术操作。
